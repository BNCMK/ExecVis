What each zoom level draws

    
Every host, service and span is on one map at all times.
    Zoom changes how much of a node is drawn, not which nodes exist. Nothing is
    added or removed as you move.

    

      
● dot under 8px: one point per node, no interior drawn

      
◎ cluster 8 to 70px: node outline, filled by status counts

      
✳ compass 70 to 260px: one line per family, at a fixed angle

      
≡ rails 260 to 700px: one row per span, drawn side by side

      
▭ span over 700px: a single call, its duration and its log lines

    


    
Colour: span status

    
greenended, status ok

    
bluestarted, no end recorded

    
redended, status error


    
Angle: syscall family

    
Inside any cluster, work points in a fixed direction by
    kind, so the same family is always in the same place: control west, IO east,
    waiting north-east, boundary south-west, faults north.
